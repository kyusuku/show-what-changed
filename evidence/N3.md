# N3 presentation and exact encoding

Goal. Implement the complete v0.1 composer for developers reviewing agent UI edits. The output is a truthful keyframe comparison whose media can be rebuilt from persisted composed images without application servers or Chromium.

Scope. Own `src/composer/**`, `test/unit/timeline*.test.ts`, `test/integration/composer*.test.ts`, and this evidence record. Shared schemas and terminal status remain root-owned.

Plan.

1. Define a pure presentation model and integer-frame schedule from the frozen CaptureBundle and ComposerSettings contracts. Write focused behavior tests for nonintegral holds, status caveats, ASCII presentation fallback, and deterministic poster selection.
2. Implement strict source/composed PNG validation using managed contained file reads, compressed byte and decoded dimension bounds. Render the fixed trusted template in an isolated registered Chromium context with CSP, local font data, PNG data, and textContent.
3. Implement system-media capability checks through the Supervisor, including an actual tiny libx264 encode and ffprobe validation. Stream one current PNG buffer with exact repetitions and backpressure, validate encoded metadata, and atomically install only validated media.
4. Run real-browser and real-FFmpeg integration cases for success, incomplete/neutral first failure, masking, injection/long-label presentation, poster, frame boundaries, faststart, input corruption, retained inputs after failures, and browser-free encoding.
5. Report exact commands, exit codes, artifacts, and remaining integration boundaries to root for independent review.

Throughput checkpoint. Establish pure schedule/status tests first, then a real rendered and encoded fixture. The release gate requires real artifact evidence rather than mocked-only checks.

Principles applied. Model the Domain selects one presentation model for titles, captions, badges and poster. Type System Discipline derives persisted types from the frozen schemas and validates imports at the boundary. Prove It Works requires decoding the actual MP4 and comparing extracted frames to scheduled PNGs.

Current status. Implementation in progress. No readiness claim.

Implemented.

- `src/composer/presentation.ts` is the pure source of presentation text, side badges, global caveats, title and step scheduling, ASCII fallback warnings, and poster tie-breaking. Source metrics and the input bundle remain unchanged.
- `src/composer/index.ts` renders the trusted version-1 template using a separate owned browser and context. Inputs are masked PNG data URLs and `textContent`. The font is embedded locally and checked against its pinned SHA-256. Network requests are blocked; CSP prohibits script, connect, frames, objects, base and form actions. Contexts have no app state or clock overrides.
- `src/composer/images.ts` checks contained regular inputs through the N1 managed reader, a 16 MiB compressed bound, PNG signature/IHDR, CRC/decode success, exact dimensions, and persisted SHA-256/byte sizes for encoding.
- `src/composer/capabilities.ts` verifies actual matching FFmpeg/ffprobe releases and performs a two-frame 16x16 libx264 encode plus decoded-frame probe. Absolute executable overrides exist only at `SWC_FFMPEG`/`SWC_FFPROBE`. No installer or browser dependency is used by encoding.
- `src/composer/process.ts` and `probe.ts` supervise argv-array commands, wait for each current PNG write to complete before sending another, consume supervisor-drained output, enforce the exact integer schedule, and verify real decoded media metadata. Encoding uses libx264/yuv420p, CFR 30, CRF 23, veryfast, faststart, no audio, and an explicit output frame limit.
- Poster restoration succeeds before the validated MP4 is atomically installed. A failed encode preserves the composed inputs and previous validated video. N1 supplies `renameRunFile(run, fromRelative, toRelative)`, streaming artifact hashing, drained subprocess output, and `reopenRunContext` ownership registration for legitimate saved-run replacements.
- `presentationWarnings(bundle, settings)` is exported from the main composer module for the root runner to aggregate into public metadata. Rendering does not mutate bundle warnings or terminal outcomes.
