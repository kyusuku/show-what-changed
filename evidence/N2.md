# N2 recorder implementation

Goal is a complete v0.1 recorder for developers reviewing agent UI edits. The frozen boundary is `capture(servers, scenarios, settings, run)` and schema commit `b792378`.

## Concrete plan

1. Model each scenario side with a live context, last safe frame, successful document and terminal failure. Keep both sides concurrent within each sequential step.
2. Implement seven fixed operations, exact locator polling, same-origin navigation and unsupported event failures under one whole-step deadline.
3. Route every real screenshot through one fail-closed mask helper. Persist numeric private PNGs and strict sanitized capture JSON through the runtime writer.
4. Run meaningful real Chromium tests for T06, T07, T08 and T09. Inspect decoded masked pixels, held states, hover persistence, timer readiness and cancellation. Record commands, outcomes and remaining gaps here.

The Model the Domain principle selected one side-state record and a terminal failure field. Type System Discipline selected schema-derived input/output types. Prove It Works requires actual browser fixtures and decoded PNG checks before completion.

## Throughput checkpoint

The first checkpoint is a compiling capture loop and a real successful two-side capture. The second is the adversarial state and mask matrix. The final checkpoint is independent review and integration by the root owner.

The recorder now detects Error-valued console arguments only while fixed time is active; ordinary string warnings remain diagnostics. No raw error data is retained.

5. `npm run typecheck` returned exit 0 after the final main-frame guards were added. The harness and integration secret fixtures now contain all secret content in the selected region. Decoded checks now reject both secret text and background colors. The real Next fixture already uses an auto-height secret container.
7. A concurrent final run caught a cancellation cleanup race with N1's immediate cancellation cleanup. Recorder and registry now share one idempotent context-close promise. A browser that has already disconnected requires no further context protocol call. Context errors while the browser is connected still propagate to cleanup.
8. Final `npm run typecheck` returned exit 0. Final `npx vitest run test/unit/scenario-states-metrics.test.ts test/integration/recorder.test.ts` returned exit 0 with 30 passing checks on macOS.
