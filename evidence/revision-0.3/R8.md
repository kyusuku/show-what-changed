# R8. Adversarial evidence inventory

The goal is a public general web-app comparison tool with useful smooth motion, preserved caller state, exact cleanup, and no private application context. This inventory maps R8 to retained tests and recorded execution. It does not accept R8 or certify a release candidate.

The review read the current working-tree tests, the R8 node in `docs/implementation-graph.md`, `spec.md`, `docs/architecture/contracts.md`, and the R2, R3, R4, and R6 evidence. It changed no product code, test, or contract. It started no application, browser, Docker, encoder, benchmark, or full suite. Test results below come from the named retained records, not a new execution by this reviewer.

Throughput checkpoint. Not applicable to this read-only investigation.

## Evidence classes

| Class | Meaning |
| --- | --- |
| Ordinary source test | Imports the working source. It can use real Git, files, processes, listeners, Python, or a browser. A `test/unit` path does not establish that a test is pure. |
| Controlled test | Uses a fake transport, fake Engine API, loader injection, spy, or synthetic resource disposer. Its real operations and injected boundaries are stated separately. |
| Source browser/media test | Uses Chromium or encoding against source imports or the source CLI loader. It does not execute a clean installed tarball. |
| Opt-in Docker test | Runs only with `SWC_DOCKER_TESTS=1`. A disabled case contributes no live Docker result. |
| Installed development run | Executes an installed, hash-identified development archive. Later source changes require a new archive and new binding. |
| Missing evidence | No matching retained behavioral case or no recent execution is identified. This label is a verification gap, not a reproduced product defect. |
